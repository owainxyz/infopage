# infopage

Source for my personal info page, a static site served with GitHub Pages.

**Live:** [owainxyz.github.io/infopage](https://owainxyz.github.io/infopage/)

## Structure

| Path | Purpose |
| --- | --- |
| `index.html` | Page content |
| `css.css` | Styles |
| `Fonts/` | Go Mono font files |
| `nix.ico` | Favicon |

## Running locally

No build step is needed. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
